# Security Policy

## Supported versions

AuraMate is pre-1.0. Security fixes land on `main` as capacity allows.

## Reporting a vulnerability

Please **do not** open a public issue for security-sensitive reports.

Use GitHub **Security Advisories** on this repository, or contact the maintainers privately.

Include:

- A description of the issue
- Steps to reproduce
- Impact assessment if known

We aim to acknowledge reports within a reasonable time. There is no bug bounty program at this time.

## Scope notes

AuraMate is local-first. Please do not propose features that capture screen contents, keystrokes, page contents, mouse trails, or detailed app-usage history.
